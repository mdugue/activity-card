## Findings considered and rejected

- Deprecated-API migrations (Next 16 middleware→proxy, legacy `next/image`, React 19 removals, Storybook `storiesOf`): none in use — nothing to do.
- `bun audit` highs: all under dev/build tooling (shadcn CLI's MCP SDK, storybook, remotion, openapi-typescript), none in the deployed runtime.
- Remotion's `zod` version warning (`remotion versions` wants 4.5.4): only matters for `@remotion/zod-types` schemas, which the compositions don't use; zod stays on the app's version.
- GPX XML entity expansion: parsing is client-side on the user's own file; fast-xml-parser v5 limits entities.
- Merging the two export sheets into one component: rejected — they already share `ExportShell`/`ExportTile`, and the families' renderers must stay separate.
- `date-fns` unused; `@remotion/cli`/`@remotion/tailwind-v4` in `dependencies` — fixed directly in the dependency-refresh commit on this branch.
