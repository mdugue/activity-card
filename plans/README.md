## Findings considered and rejected (do not re-audit)

- **SameSite=Lax on OAuth/token cookies** — by design; the OAuth top-level
  redirect must carry the state cookie. Strict would break the flow.
- **`safeRelativePath` open-redirect concern** — already defended; callback
  re-validates origin (`app/api/strava/callback/route.ts`).
- **Carousel pixel-ratio cap degrades long carousels** — unreachable today:
  max theme is 4 panels → width 4320 → `floor(16384/4320)=3` ≥ the 2×
  target. Only relevant if a theme ever exceeds 7 panels.
- **"recharts ships ~100-200KB to every visitor"** — false: `ui/chart.tsx`
  is never imported, so it's not in any bundle. The true cost is dependency
  surface → handled as plan 001.
- **Manual `useMemo` sweep across editor/theme components** — React
  Compiler is enabled; the flagged sites are auto-memoized. Re-open only
  with profiler evidence of compiler bail-outs.
- **Loosen Remotion's exact version pins to carets** — inverted: Remotion
  officially requires all `@remotion/*` packages on identical versions;
  exact pins are correct.
- **"tsgo missing from PATH / brittle"** — it's a package bin run via
  `bun typecheck`; works. The preview-compiler risk is real but mitigated
  by stable `typescript` also being installed as an escape hatch.
- **XMLParser entity-hardening (`processEntities: false`)** — fast-xml-parser
  v5 resolves no external entities and blocks nested expansion; parsing is
  client-side on the user's own file. Not worth config churn.
- **"No add-a-theme guide"** — `docs/creating-a-theme.md` exists and is
  linked from AGENTS.md.
- **Demo mode / sample activities** — already shipped: the onboarding wizard
  offers built-in samples (`components/app/onboarding-wizard.tsx:88-95`).
- **CSRF token framework for the API** — overkill; only one state-changing
  endpoint exists and a fetch-metadata guard suffices (plan 005).
- **Husky/lefthook pre-commit hooks** — judgement call: CI is fast and
  comprehensive; hooks add friction for marginal gain on a solo repo. Revisit
  if CI-failure round-trips become a complaint.
- **`ignoreScripts`/`trustedDependencies` sharp cruft** — sharp and
  unrs-resolver ARE in the lockfile (transitive); the config is plausibly
  load-bearing for bun installs. Left alone deliberately (noted in plan 001).
- **Various LOW-confidence correctness reports** (empty-array Math.min in
  chart-helpers, `units()` division, `.at(-1)` casts, sequencePaths
  indexing) — verified guarded or correct on read; the audit's own agent
  withdrew most of them.
